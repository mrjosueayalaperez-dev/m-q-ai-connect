# M&Q AI CONNECT

**Shared Intelligence & Implementation Layer for the M&Q AI Ecosystem**

*We are not building one giant AI that owns all our projects.
We are building an intelligence layer that helps each independent project become stronger.*

---

## What this is

M&Q AI CONNECT is the shared intelligence and implementation layer for the M&Q ecosystem. It supplies reusable AI capabilities, founder-approved knowledge, standard workflows, and verified integration patterns so that each independent project can become stronger without losing its own mission, audience, or data boundaries.

This repository is the layer's public home: the adopted founding blueprint, the capability registry, the integration registry, and the versioned capability documents themselves.

## The independent projects it serves

- **M&Q University** — free MNQ futures education. *Knowledge is the legacy.*
- **Plates for Hope** — community meal coordination.
- **One-Minute Page** — one-minute creative pages for local shops.
- **Community Bridge** — bilingual community-resource finder (Fellsmere / Sebastian / Vero Beach, FL).
- **Family Bridge** — bilingual guide for families of detained immigrants.
- **MNQ Scalp Stacks** — trading intelligence and doctrine.

## The rules that do not bend

- Projects remain structurally independent: separate databases, permissions, users, and operational boundaries.
- Sharing happens only at the founder's layer — infrastructure, standards, design, workflows, AI assistance.
- Private user information never crosses project boundaries. The three bridge projects (Plates for Hope, Community Bridge, Family Bridge) remain fully separate in data and operation. No merged databases.
- Every connection is verified before it is called "connected." One verified integration at a time.
- Nothing enters the capability library until it has been used successfully in at least one project and reviewed under the verification standard.
- Value is measured by documented time or cost savings and operational reliability — never by income promises.
- No secrets, credentials, or private data are ever committed to this repository.
